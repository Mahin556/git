
## **1. See Help for a Specific Command**

* **Full manual page**

```bash
git help <command>
```

> Example: `git help commit`

* **Alternative syntax (same as above)**

```bash
git <command> --help
```

> Example: `git status --help`

* **Quick summary of options (no full manual)**

```bash
git <command> -h
```

> Example: `git add -h`

---

## **2. List Git Commands**

* **List all available Git commands**

```bash
git help --all
```

> Shows every command grouped by category (Porcelain, Low-level, etc.)

* **List guides and concepts**

```bash
git help -g
```

> Shows learning guides like `attributes`, `everyday`, `glossary`, `revisions`, etc.

---

## **3. Tips for Using Git Help**

* Use arrow keys / Space to scroll down, `b` to scroll up.
* Type `/` followed by a word to search; press `n` for next match.
* Press `q` to quit the help viewer.
* If the help page doesn’t open, use `git <command> -h` for a quick summary.
* `SHIFT + G` jumps to the end of long lists in the help viewer.
